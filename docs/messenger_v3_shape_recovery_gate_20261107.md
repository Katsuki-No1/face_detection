# Dataset V3で学習した復元器と位置誤差ゲート

Dataset V3 MAL alpha2 Queryのepoch 15 EMA（SHA-256 11b430b595e56395a14c266cb364bd50848b1a51b5b689548eb6749de0a23856）から、顔crop後のDINOと位置headを固定して使用した。V3の回転軸補正済みtrain注釈と同一SHAの画像を使用。単一スケールのMessenger復元器Rとパッチ採用率gは新規初期化した。融合は Y = X + g (R − X)。旧k=3の重みと統計バンクは使用していない。

| V3 train内の役割 | 動画 | 座標のある自然顔 | 遮蔽前画像に適格な顔 | 人工ペア（3形状計） |
|---|---:|---:|---:|---:|
| 学習 | 147 | 15,778 | 6,053 | 18,159 |
| モデル選択 | 16 | 1,934 | 739 | 2,217 |
| 最終比較 | 40 | 4,662 | 1,896 | 5,688 |

各役割は動画IDと画像SHAで互いに分離。固定したV3 Queryの既存学習にはグローバルtrainが含まれるため、この最終比較は新しいR・gに対するtrain内評価である。GT楕円を1.25倍にして256×256へcropし、特徴キャッシュはFP16、最適化はFP32（GPU行列演算はTF32許可）。評価値はcropを条件とする。

## Rの教師と学習

全5点可視かつ輪郭非遮蔽の各顔に、傾きを変えた線、額・耳・頬・顎からなる顔形状、掌・親指・4本の指からなる手形状を1つずつ配置した。形状によらず色と低周波テクスチャを乱数で与える。実写の手や顔を貼る条件とは分けて扱う。対象楕円面積の10–40%を覆い、実マスク内に少なくとも1つの注釈点を含む。学習の全18,159対で条件を確認した。マスクとテクスチャは顔と形状から決まる固定seedを使用し、3 epochで全形状が一巡する。

合成前の同じ顔の固定DINO特徴を教師とし、人工遮蔽に触れる顔内パッチのコサイン距離＋MSEと、遮蔽外の同じ誤差（重み0.1）を最小化。AdamW、batch 32。最初の12 epoch（LR 3e−4）の選択損失は0.13254→0.07931。12 epoch目も改善したため、同じ学習対を使い、選択した重みから新しいAdamW（LR 1e−4）で継続した。追加16 epoch目で選択損失が最小0.07056となり、その後6 epochで改善が止まった。合計28 epoch時点のRを採用。保存済みRを読み直して固定した後、自然画像の全座標に等重みのSmooth L1（beta 0.02）を用いてgだけを学習した。AdamW、batch 32、LR 5e−4、8 epoch中の選択損失が最小のepoch 7を採用した。headからgへの非ゼロ勾配と、固定モデルの重みの一致を確認した。

## 自然画像のhead性能

| GTの状態 | 平均g | 正しい位置出力 X → Y | 平均位置誤差（楕円長径比）X → Y |
|---|---:|---:|---:|
| 自然遮蔽 | 0.103 | 2,367 → 2,406 / 3,082 | 5.901% → 5.742% |
| 可視 | 0.046 | 16,247 → 16,291 / 17,004 | 2.112% → 2.116% |

自然遮蔽点の成功率差 +1.27ポイント（動画単位の対応付きbootstrap 95%区間 +0.58〜+1.96ポイント）、平均誤差差 −0.159ポイント（−0.228〜−0.090）。可視点の成功率差 +0.26ポイント（+0.12〜+0.41）、平均誤差差 +0.004ポイント（−0.022〜+0.036）。自然遮蔽のGT点と可視点をgで順位付けしたAUROCは0.717。これは位置損失のみで訓練したゲートの補助診断。自然遮蔽自体の復元特徴には遮蔽前の正解がない。線のみで訓練した対照がないため、各追加形状の因果的寄与は未測定。

## 自然遮蔽での融合の強さ

同じ4,662顔で、自然遮蔽点を含むパッチのgは平均0.103、中央値0.042、90パーセンタイル0.282、0.5以上115 / 3,082点。可視点では平均0.046、中央値0.009、0.5以上265 / 17,004点。0.5は寄与を見るために採用した診断境界で、通常の推論は連続値を使う。

保存済みRとgで同一CPU headを再実行した。全空間パッチで学習済みgをそのまま使うか、条件に該当するパッチだけに残して残りを0にした。自然遮蔽点について、g=0では2,368点成功・平均誤差5.901%、g≥0.5のパッチのみでは2,388点・5.855%、g<0.5のパッチのみでは2,394点・5.770%、通常融合では2,406点・5.742%。高いgのパッチと低いgのパッチのどちらからも寄与があり、headの応答は非線形で成功点数の差は単純に足せない。全パッチでmin(2g,1)にすると2,430点・5.775%。可視点の平均誤差は通常2.116%から倍増時2.178%へ上昇。元のGPU評価とCPU再計算では成功閾値付近の集計が最大1点違うため、介入比較はCPU同士で統一した。[介入結果](../outputs/diagnostics/v3_shape_recovery_gate_20261107_refined/gate_strength.json)
