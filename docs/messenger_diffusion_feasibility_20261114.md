# Messenger特徴復元の局所診断とDiffusionの導入価値

2026-11-14。DFをDiffusion（拡散モデル）として調査した。新規学習は行わず、保持済みscale C／level＋scale Cの重みを固定し、以前と同じ人工遮蔽評価128顔・384対・35動画・実際に覆われた663点を再推論した。主候補scale C、代替level＋scale Cの選定は維持する。

結論：課題は復元特徴の利用方法だけではない。点周辺でも特徴誤差は大幅に改善しているが、空間的な変動は正解より小さく、既知の遮蔽領域だけに復元を適用しても位置誤差の平均は悪化する。同領域への正解特徴の挿入は改善するため、復元特徴の質／固定headとの適合性が残る。条件付き特徴Diffusionを比較する価値はあるが、現行モデルの即時置換を支持する結果はまだない。

## 1. 現行モデルで最小化しているもの

`src/models/messenger_multiaxis.py`のRは独立cross-attention・幅96・2層・6headで384ch特徴を出力する。Cの損失は融合後＋各枝の「cosine距離＋raw MSE」、枝間MSE×0.1。顔楕円内の人工遮蔽パッチを重み1、非遮蔽部を0.1とする。点周辺専用の損失や、固定headの座標・presence・内部表現を復元器Rに戻す損失はない。自然画像で位置損失を使うのは後段のgだけであり、Rはそこで固定される。

したがって平均パッチ誤差が最小の特徴が、固定headに最適とは限らない。headはcross-attentionを介して特徴マップを参照するので、GT点を含む1パッチだけで位置を決めるモデルでもない。幅96の圧縮、独立位置queryからのdecode、枝間一致による正則化、学習データ量、人工→自然の分布差も候補原因であり、MSEだけに原因を帰属できない。

## 2. 新たな局所診断

特徴誤差はcosine距離＋MSE。GT点を含む16pxパッチと、その3×3パッチ近傍で測定する。3×3は画素単位の精密復元を測る指標ではない。点近傍を重複して数える点単位平均で、全遮蔽パッチ平均とは重みが異なる。

| 指標 | 人工遮蔽入力X | scale CのR | level＋scale CのR |
|---|---:|---:|---:|
| 全遮蔽パッチの特徴誤差 | 0.29531 | 0.11164 | 0.11330 |
| 覆われたGT点のパッチ誤差 | 0.46157 | 0.13566 | 0.13511 |
| 同点の3×3近傍誤差 | 0.32690 | 0.11368 | 0.11517 |
| 楕円内・非遮蔽パッチ誤差 | 0.03546 | 0.09962 | 0.10332 |
| 3×3近傍の空間分散／正解の空間分散 | 1.081 | 0.589 | 0.557 |

局所誤差も約71%減少した。「全体の平均だけ良くなり、点近傍は全く改善していない」という仮説には反する。中心パッチ誤差が改善した点はscale Cで628/663、level＋scale Cで630/663。

一方、近傍の各特徴ベクトルから近傍平均を引いた二乗偏差をチャンネル・位置で平均した空間分散は、正解の58.9%／55.7%。動画単位bootstrap95%区間はそれぞれ55.2〜62.4%／52.1〜59.2%。局所的な変動が弱くなったことを示す。ただし、この値だけで正しい細部が欠落したのか、振幅が縮小したのか、条件付き平均に近づいたのかは確定しない。チャンネル間構造や位置応答の鋭さも別途評価が必要。

scale Cでは、中心特徴誤差が改善したにもかかわらず、全R入力時の座標誤差が悪化した点が364/663あった（level＋scale Cは382/663）。この対応は損失と下流精度の不一致を示すが、headが全体を参照するため、局所特徴だけが原因という因果的証明ではない。

## 3. 正しい遮蔽範囲を知っている場合の介入

遮蔽maskは元実験と同じ人工maskを16×16パッチへ変換し、顔楕円supportと交差したもの。自然遮蔽を検出した結果ではなく、範囲を知っている診断用条件。Xは人工遮蔽後の特徴、Zは同じ顔の遮蔽前特徴、Rは復元特徴。遮蔽範囲以外のXもViTの文脈混合によりZと一致するとは限らない。

| headへの入力 | scale C 成功 /663 | scale C 平均位置誤差 | level＋scale C 成功 /663 | level＋scale C 平均位置誤差 |
|---|---:|---:|---:|---:|
| Xそのまま | 634 | 3.713% | 634 | 3.713% |
| 全マップをR | 622 | 4.607% | 628 | 4.793% |
| 既存の学習済みgで融合 | 635 | 3.657% | 639 | 3.541% |
| mask内R、外X | 638 | 4.063% | 639 | 4.120% |
| mask内Z、外X（正解特徴の介入） | 655 | 1.656% | 655 | 1.656% |
| mask内R、外Z（外側も正解） | 643 | 3.963% | 643 | 4.009% |
| 全マップZ（遮蔽なし） | 655 | 1.572% | 655 | 1.572% |

成功はpresence≥0.7かつGT楕円長径で正規化した座標誤差≤10%。平均位置誤差は663点すべての座標誤差で、presenceを通過した点だけに限定しない。元の復元実験と同じ診断定義であり、productionのHead正規化NMEとは別物。

mask内Rは成功数が4〜5点増える一方、平均位置誤差が悪化する。scale Cの差は+0.351ポイント、動画対応95%区間+0.107〜+0.569。level＋scale Cは+0.407、+0.182〜+0.606。成功率差の区間は両方ゼロを含む。mask内Zの成功は+21点、scale Cの成功率差区間+1.56〜+5.02ポイント、平均位置誤差差−2.057ポイント（−2.311〜−1.818）。2,000動画bootstrap、探索的・多重比較未調整。

解釈：非遮蔽部までRへ置換する悪影響は存在するが、maskを正しく与えるだけではRとZの差は解消しない。元の非遮蔽情報を保持しつつ、headに必要な構造を保つ復元が必要。正解挿入は実用可能な上限保証ではなく、同じheadに改善余地があることを調べる対照である。

自然画像には遮蔽前の対応特徴がないため、この局所特徴精度・平滑化の測定は人工遮蔽に限る。以前の自然点成功257/349はこの663点と別の集合。今回、自然遮蔽の性能が改善したとは主張しない。

## 4. ViT、MSE、Diffusionの整理

ViTはネットワーク構造、Diffusionは分布を学んでサンプリングする枠組み。両立する。DiTはTransformerを拡散モデルのdenoiserに使うため、変更対象は「ViTそのもの」よりも「一度で決定的に復元する方式」である。[DiT, ICCV 2023](https://arxiv.org/abs/2212.09748)

純粋な二乗誤差回帰の理想解は条件付き平均 E[Z|X]。同じ観測から複数の局所構造があり得ると、その平均が実際のどの構造にも似ない可能性がある。この性質はViTに限らずCNNにも当てはまる。現行はcosine＋MSE＋枝損失なので、厳密に条件付き平均そのものになるとは言わない。平均誤差と自然らしい分布の再現が異なることはperception–distortionの研究とも整合する。[Blau & Michaeli](https://arxiv.org/abs/1711.06077)

Diffusionも代表的なDDPMではノイズ予測に二乗誤差を使う。MSEを捨てるから平均化を回避するのではなく、ノイズ強度ごとのdenoisingを学び、初期ノイズから逐次的に条件付き分布の候補を生成する点が違う。[DDPM, NeurIPS 2020, Eq.14](https://arxiv.org/pdf/2006.11239)

ただし、もっともらしい目や口を生成することと、その画像のGT位置を当てることは違う。観測から区別できない複数候補があるなら、単一のランダム生成がGTと一致する保証はない。生成特徴を平均してからheadへ入れると、避けたかった平均化が再び生じ得る。複数候補を扱うなら各候補にheadを適用し、GTを参照しない選択または予測分布の扱いを定める必要がある。

## 5. 関連する一次研究と今回への適用範囲

| 研究 | 確認した内容 | 今回への示唆と限界 |
|---|---|---|

これらは「拡散モデルに価値がある」根拠だが、「今回のRを小規模データで拡散モデルに変更すれば解決する」という直接の証明ではない。強い事前学習を借りる効果と確率的復元方式の効果は分けて考える。

## 6. 置き換える価値と推奨比較

判断は **条件付き特徴Diffusionを研究候補として比較する価値あり、現時点での全面置換は保留**。現行scale Cの局所誤差は既に改善しているので、まずheadに有効な情報が残る復元・可視領域の保護を比較軸に置く。平均誤差だけでDiffusionの採否を決めない。

方式を比べるなら、DINOと既存headを固定し、復元先も同じ16×16×384特徴空間に揃える。RGBを生成して再びDINOへ通す方式は、本人形状・幾何の変化と計算量の要因が増えるため最初の比較から分ける。条件は遮蔽画像から得るmulti-scale特徴と遮蔽度の予測。教師は人工遮蔽前のDINO特徴。特徴の正規化統計はtrainのみから固定する。Transformerをdenoiserとして使うことは可能。

因果を分ける最小比較案は次の2×2（未実行）。

| 復元方式 | 特徴復元のみの学習 | headを意識した損失も追加 |
|---|---|---|
| 決定的なscale C | 現行基準 | 同じ特徴損失＋局所構造／固定headの補助損失 |
| 条件付き特徴Diffusion | denoising目標のみ | 同じdenoising目標＋上と同じ補助損失 |

補助損失はGT点近傍での復元、局所の空間差分や相関、固定headに融合特徴を入れたGT座標・presence／clean-head表現の一致から少数を事前に定める。すべて一括で追加すると何が効いたか分からないため、一つずつ確認する。headの重みを更新せず、その勾配を復元器へ戻す。clean-headの誤りもあるため、教師head一致だけを位置の正解としない。headを適応させる実験は別軸とする。

人工では同じ既知maskで利用範囲を揃える。自然では以前のsoft遮蔽教師＋位置損失を用いるgの同じ学習手順を各方式に適用し、GT領域を推論入力にしない。以前のGT補間mask自体も真の密な遮蔽注釈ではない。自然画像を単純にg=1で切り替える設計と、soft教師でgを学ぶ設計は分けて評価する。

Diffusion側は学習時に単一tを抽出する一般的方式が使えるが、推論ではdenoiserの反復回数と候補数分の費用が加わる。例えば8／16ステップ、1／4候補の限定比較を事前固定し、実測遅延・VRAMを報告する（この数字は検討案であり最適値ではない）。元の256顔だけで新しい分布モデルを十分学べる保証はない。最終比較は同じtrain分割・同じデータ拡大量・複数seedで行い、モデル容量と学習計算量を併記する。既存9条件の再利用evalは探索用として扱い、最終採否は未使用の評価データで確認する。

枝間一致を拡散モデルへ移す場合、別ノイズから得た候補を直接一致させると多様性を潰す可能性がある。同じノイズ・時刻・生成候補を各枝で共有する設計とし、異なるサンプル間の多様性は別に扱う。独立生成結果の特徴平均だけで評価を終えない。GTに最も近い候補を選ぶbest-of-Kはoracle診断に限り、実用成績としない。

採否指標：自然遮蔽点の位置誤差分布・成功率、可視点の精度維持、presence、動画時系列の揺れ、人工の点近傍特徴誤差・空間変動・head出力、推論時間。Diffusionの特徴誤差が多少悪くても、headの位置精度・頑健性が改善すれば価値がある。逆に局所変動が正解に近づいても位置が改善しなければ採用理由にはしない。
