## 1. 元特徴がNMEで最良か

ここでいう元特徴Xは人工／自然遮蔽画像から取得したDINO特徴。今回の位置誤差はGT顔楕円長径で正規化した平均座標距離で、productionのHead正規化NMEとは別。

- 自然遮蔽：元特徴6.577%に対し、学習済みgで融合した回帰／回帰head／DF／DFheadは7.068/7.015/6.988/7.027%。今回の4条件では元特徴が最良。
- 人工遮蔽の既知mask内完全置換：元特徴3.713%に対し4.054/4.091/4.201/4.149%。元特徴が最良。
- 人工遮蔽の学習済みgによる混合：3.516/3.555/3.541/3.534%で元特徴より小さい。したがって「どの条件でも元特徴が最良」「全く利用価値がない」とは言わない。ただし自然遮蔽での位置改善は確認できていない。

## 3. 現行損失・構造との対応

### 特徴距離とheadが必要とする距離が異なる

MSE部分は各チャンネルの二乗誤差を等しく平均する。cosineはベクトルの全体方向を見る。いずれも、その成分が眼／鼻／口の座標を何px動かすかを重み付けしていない。

headの座標出力をH(F)とすると、小さな特徴変化に対して `ΔH ≈ J_H(F) ΔF`。MSEが小さくても、headの感度が高い方向に誤差が残れば位置は動く。これは数理的な説明候補であり、今回Jの実測はしていない。「眼を表す特定チャンネルが消えた」と特定できる証拠もない。

head実装は、memory projectionとQuery cross-attentionに加えて、予測点近傍の特徴をbilinear samplingし局所補正する。したがって、各点の中心ベクトルの一致だけでなく、近傍の差分の方向・周辺との関係・チャンネルの組み合わせが位置決定に影響し得る。attentionの強さだけを重要性や因果効果とは扱わない。

### 一致度を優先する構造上の候補

復元器は384チャンネルを幅96へ投影し、各位置queryが共通memoryを読む。各枝は出力位置query同士のself-attentionを持たず、Rへの直接的なX残差経路もない。枝Cでは共通教師への一致と枝間MSEを課す。位置関係の表現力、圧縮、枝の多様性への影響は候補原因だが、個別ablationなしに原因確定はできない。16×16解像度や小規模fit256顔も併存する制約であり、損失だけに責任を帰属しない。

### head補助を入れても選択基準が特徴誤差のまま

`run_messenger_diffusion_comparison.py`ではhead補助は最終座標のSmoothL1（beta0.02、係数10）。全注釈点の平均で、遮蔽点と可視点の別平均や局所構造への直接損失はない。係数10だけで勾配の強弱は判断できず、損失別の勾配ノルム・方向は未計測。

| 条件 | 特徴最良の選択epoch | dev位置損失最小epoch | 選択時の位置損失の相対超過 |
|---|---:|---:|---:|
| 回帰 | 95 | 70 | 0.51% |
| 回帰＋head | 124 | 12 | **8.27%** |
| DF | 227 | 191 | 0.37% |
| DF＋head | 227 | 191 | 0.41% |

回帰＋headの検証位置SmoothL1は12epochで0.0070063、採用124epochで0.0075861。特徴は0.17033→0.10918へ改善する一方、位置指標は悪化していた。これは保存ログの比較であり、epoch12のモデルを新たに評価・採用した結果ではない。中間重みがすべて残っているという意味でもない。8.27%はNME改善率ではない。

さらに、R補助学習は既知mask内を完全置換した入力だが、自然推論は学習済みgの連続融合。DF補助はnoisy cleanから1回のdenoiseで推定したx0にかかり、実際の16step sampling出力への補助ではない。最終利用時の入力経路と学習目的が完全には揃っていない。

## 4. 画像生成・復元の一次資料

下表は論文で確認した設計。Messengerへの適用は本調査の提案であり、これらの論文がDINO特徴の顔キーポイント復元で効果を実証したという意味ではない。

| 研究 | 損失設計の要点 | 今回への示唆 |
|---|---|---|
| [Johnson et al., ECCV 2016](https://arxiv.org/abs/1603.08155) | 画素の差に代えて学習済みネットワークの表現上で差を測る知覚損失 | 何の表現で差を測るかが重要。現行もDINO空間の差だが、それだけで座標に適した距離とは限らない |
| [ESRGAN](https://arxiv.org/abs/1809.00219) | 知覚損失・敵対的損失を改善し、活性化前特徴による監督を使用 | 細部・分布の再現を重視。ただし写真らしい目や口と、その画像のGT位置の一致は別 |
| [LaMa, WACV 2022, §2.2](https://arxiv.org/pdf/2109.07161) | 広い受容野の知覚損失、局所patch識別器、識別器feature matching等 | 局所自然さと広域構造の両方を監督。パッチ単独の誤差だけにしない |
| [SPSR, CVPR 2020](https://arxiv.org/abs/2003.13081) | 勾配mapを復元し、画像の勾配に対する損失で構造を保護 | 特徴の隣接差分の大きさ・符号・方向を比較し、位置関係を監督する候補 |
| [Focal Frequency Loss, ICCV 2021](https://arxiv.org/html/2012.12821v3) | 復元しにくい周波数の誤差を適応的に重くする | 高周波の量だけ増やさず、目標との不一致を減らす。特徴空間への移植効果は未確認 |
| [Latent Perceptual Loss](https://arxiv.org/html/2411.04873v2) | 潜在空間の二乗誤差と後段decoderとのずれに着目し、decoderの複数段の表現で監督 | 今回に近い問題設定。「後段が使う情報に合わせた損失」を設計する根拠。原法そのままの移植はしない |

画像の知覚品質と平均歪みには異なる目的があることは[Perception–Distortion Tradeoff](https://arxiv.org/abs/1711.06077)でも論じられる。ただし、その理論だけで今回の位置悪化の原因やMSEの責任が証明されるわけではない。

Diffusionも通常のノイズ／v予測では二乗誤差を使う。二乗誤差をなくすこと自体ではなく、比較する表現・空間関係・重要度と後段の目的を揃えることが焦点。L1に置き換えるだけでも位置精度が保証されるわけではない。

LPLの原法は正解latentもdecoderに通すが、ユーザー指定により今後その形の正解特徴head比較は行わない。取り入れるのは後段への適合という考え方であり、こちらの損失は復元／融合特徴のhead出力とGT座標を用いて定める。

## 6. 次の最適化の優先順位

1. **主評価・checkpoint選択を位置へ揃える。** 実際に使う融合経路のdev遮蔽点平均正規化誤差を主指標とし、可視点の悪化許容を事前固定する。中央値・P90・2/3/5%座標成功曲線も記録。presence込み成功と分離し、presence選別で難点を母数から落とさない。自然devが小さいため、分割を固定して多重な調整を抑え、evalを選択に使わない。
2. **座標GTへの損失を主目的として扱う。** head補助を再追加しただけとせず、遮蔽／可視を別平均し、最終出力と必要なら中間座標に監督。元と同じ学習条件の対照を用意し、勾配の競合を測る。自然推論で使うg経路と整合させる。
3. **空間構造損失を1つ追加して比較。** 最初はGT点近傍のsigned x/y特徴差分と目標差分の一致。単なるTV（平滑化）や分散を大きくする損失にしない。特徴距離は補助として残す。
4. **必要性が確認された場合のみ重要度／周波数損失へ。** 感度の高い特徴方向への重み付けや複素周波数誤差を別条件で比較。無重みの全周波数L2は正規化次第で空間L2と等価になるため、FFTへ移しただけでは新しい目的にならない。

設計の概念式：`L = L_position_GT + λstruct L_local_difference + λfeat L_feature + λstate L_presence`。係数は未決定。これを一度に全部導入して原因を不明にせず、まず選択基準・推論経路の整合、次に局所構造を切り分ける。位置損失はGTへ、構造・特徴損失は特徴教師へかけ、正解特徴head出力を教師にしない。自然遮蔽では特徴教師を捏造せず座標GTで評価する。

敵対的損失やDFへの全面移行は、この段階の最優先ではない。既存DFは変動を増やしても位置精度を改善しておらず、まず「正しい場所に必要な構造を復元できるか」を学習と選択で評価する。

## 7. ユーザー指定の主損失と現行DFの確認（2026-11-18追記）

ユーザー指定：「主損失をhead予測の位置誤差として、復元特徴の精度、MSEとcosine類似度は補助損失とする」。今後の設計方針として採用。過去の実験は異なる目的・選択基準で実施した記録を維持し、既存実行ソースは書き換えていない。今回、実装変更・学習開始はしていない。

### LaMaでいう知覚損失と敵対的損失

[原論文§2.2、式1・4・5](https://arxiv.org/pdf/2109.07161)を確認。広い受容野を持つ学習済みネットワークφに、復元画像と対応する正解画像を通し、その中間特徴の二乗差を層ごとに平均するのがHRF perceptual loss。画素の一対一の差ではなく、広い範囲を表現した特徴の差を監督する。LaMaではセグメンテーションで学習したネットワークを用い、形状・大域構造の整合を重視する。

局所的な敵対的損失ではpatch識別器Dを学習する。正解画像のpatchはreal、復元画像のmaskと交差するpatchはfake、既知領域はrealとして識別器を学習し、生成器側は復元画像をrealと評価させるnon-saturating損失を最小化する。これは局所の自然さを促すもので、その画像のGTキーポイントとの厳密な一致を直接保証しない。

加えて識別器の中間特徴を合わせるfeature matchingと、識別器の入力勾配を抑えるR1正則化を使う。前者は生成学習の安定化、後者は識別器の過敏な反応の抑制に使う。これらをMessengerへ追加する決定ではなく、損失の説明である。

### 現行DFの学習損失

正解特徴Zをtrain由来のチャンネル平均・標準偏差で標準化したzを用いる。

`z_t = α_t z + σ_t ε`、`v_target = α_t ε − σ_t z`。

現行コードは `α_t=cos(πt/2), σ_t=sin(πt/2)`。ここでcosはノイズ量を変える三角関数であり、特徴ベクトル間のcosine類似度損失ではない。

`L_DF = MSE(v_fused,v_target) + mean_b MSE(v_b,v_target) + 0.1 mean_pairs MSE(v_b,v_b')`。

各項の領域集計は遮蔽領域平均＋0.1×顔内非遮蔽領域平均。復元特徴は `R=(α_t z_t−σ_t v_pred)*std+mean`。固定t・noiseの下では特徴誤差はv誤差に `−σ_t*std` を掛けたものに対応するが、これはノイズ時刻・チャンネル依存の重みを持ち、最終sampled Rへの一様な特徴MSE＋cosineとは異なる。

| 用途 | 回帰 | DF |
|---|---|---|
| 復元器の通常学習 | RとZのMSE＋cosine距離、各枝も同じ教師 | v予測のMSE、各枝も同じv教師 |
| 枝間一致 | 枝の復元特徴どうしのMSE | 枝のv予測どうしのMSE |
| head補助あり | 上記＋10×最終座標SmoothL1 | 上記＋10×推定x0経由の最終座標SmoothL1 |
| RとZのcosine距離を学習へ逆伝播 | あり | **なし** |
| 実際の生成RとZのMSE＋cosine距離 | 学習・評価・最良R選択 | **評価・最良R選択のみ** |

現行DFでMSEとcosineを両方学習していた、という解釈は誤り。DFのcosineは最良重み選択で参照されていたが、勾配には入っていなかった。head補助は学習中のnoisy cleanから得た推定x0へかかり、16step生成全体への逆伝播ではない。

### 指定方針に沿った今後の形

回帰の基本形：`L = L_position(H(F_use), GT_xy) + λm MSE(R,Z) + λc [1−cos(R,Z)]`。

F_useは実際にheadへ渡す融合特徴。位置を主目的とし、MSEは成分値・大きさ、cosine距離は特徴ベクトルの方向を補助的に保つ。位置誤差は全有効GT点を母数にしてpresenceで難点を除外しない。遮蔽／可視の集計と重みを明示する。

DFでは上記にv予測目的を補助として残す案がある：`L = L_position + λm L_feature_MSE + λc L_feature_cosine + λv L_v`。DFの特徴MSE＋cosineを勾配へ入れるなら現行からの追加実装になる。枝間一致の扱い、各係数、時刻の重み、位置／特徴補助を推定x0またはsampling出力のどちらへかけるかは未決定。最終推論経路とのずれを明示して比較する。

主／補助は係数の数値だけで判断せず、勾配の規模・方向を計測する。最良checkpointも実際の推論経路のdev位置誤差を優先し、特徴距離最小への選択は継続しない。正解特徴をheadへ与える比較は行わない。
