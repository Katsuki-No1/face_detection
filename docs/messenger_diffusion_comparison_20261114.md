# Messengerの回帰／Diffusion × head補助損失の4条件

ユーザーが2026-11-14に4条件の収束までの学習、特徴・head位置精度比較、自然遮蔽で以前の遮蔽教師を使うこと、全数値評価終了までの重み保持を指示。入口は`scripts/run_messenger_diffusion_comparison.py`、出力は`outputs/diagnostics/messenger_diffusion_comparison_20261114/`。

## 学習前に固定した条件

- `det_feature`: 現行scale C、cosine＋MSEの融合／各枝復元と枝間一致。
- `det_head`: 同構造・初期値に固定headの座標SmoothL1（beta0.02、係数10）を追加。
- `diff_feature`: 条件付き特徴Diffusion、同じscale1/2/4の独立attention枝。cosine VP、v予測の融合MSE＋枝平均MSE＋0.1枝間MSE。領域重み1/0.1。
- `diff_head`: 同じ拡散構造・初期値・ノイズに同じhead座標損失を追加。学習時のnoisy clean特徴から復元したx0をheadへ入力する。16ステップ全体への逆伝播ではないため、補助学習と実際のsamplingには差があることを明示する。

head補助は既知の人工遮蔽パッチ内にR、外に元特徴Xを入れる。全注釈点を等重みにし、headの重みは固定。位置損失だけを追加し、局所勾配・presence・知覚損失などを一括追加しない。係数10は事前固定の実装選択で、最適化済みではない。

全条件seed42、batch16、FP32/TF32、AdamW（R初期1e-4、g5e-4、weight decay0.01）、clip5。新規初期化。人工fit256/dev128/eval128顔×3形状、自然fit512/dev128/eval512顔は前回9条件と同一manifest。固定親V3 Query epoch15 EMA、GT crop256、DINO最終特徴16×16×384。train内の動画分割。global val/testや全件本学習ではない。Diffusionの特徴正規化は人工fitの遮蔽前256顔のみ、channelごとのmean/std、std下限0.01。

Diffusionの主推論は16ステップDDIM相当の決定的更新、初期ノイズseed42。入力IDに固定したノイズで、バッチ分割に依存しない。検証のノイズ・時刻を固定し、評価後に生成seedを選ばない。最終数値評価では1042/2042/3042も追加し、特徴を平均せず個別のhead性能を記録する。異なる候補間の一致を課さず、枝間では同じnoisy target・tを使う。幅・memory枝を共通化するが、Diffusionのノイズ／時刻投影による追加パラメータと反復計算量は同一ではない。

## 自然遮蔽の教師

`src/data/natural_gate_teacher.py:patch_teacher`をそのまま再使用。顔楕円内の5点可視／遮蔽状態を滑らかに補間し、遮蔽された眼と口角の間に可視鼻がある場合は鼻の高さに谷を置く。凸包外は信頼重みを弱める。旧採用コードのSHAとクロップ座標の一致を検証する。

gは位置SmoothL1＋0.1 confidence-weighted soft BCE。R・DINO・headは固定。推論の融合は`X+sigmoid(g)*(R-X)`、遮蔽GT点や教師マップは入力しない。旧マップは弱い採用率教師であり、正確なpixel遮蔽maskでも、推論で遮蔽領域をg=1に固定する指定でもない。

## 選択と収束

- Rは全4条件でdevの遮蔽部cosine＋MSE最小を最良checkpointとする。停止監視はその指標・生成結果のmask限定head位置損失・各条件の学習目的の3つ。最低40epoch。
- gはdev位置＋0.1soft BCE最小を選択。停止監視は合計・位置・BCEの3つ。以前の位置だけの最良選択から変更し、遮蔽教師への適合も選択に含める。最低20epoch。
- 各監視指標の0.1%または絶対R1e-5／g1e-6の大きい方を超える減少を進捗とする。8epoch進捗なしで学習率を半減。R1e-6／g5e-6の下限で15epoch進捗なしなら検証plateauとする。どれか一つが改善していれば継続。
- 安全上限R600／g300epoch。上限は収束と扱わず、lastを保存して停止・報告する。大域最適や学習損失の完全収束の保証ではない。
- 各条件best R/gとoptimizer・controller・RNG付きlast R/gを保持。全16checkpointを自動削除しない。中断時はプロセス／canonical leaseを確認して`--resume`、plan・source・dataが同じことを要求。

## 評価と実行管理

人工：遮蔽／非遮蔽特徴誤差、GT点パッチと3×3近傍誤差、局所空間分散、元特徴／全R／学習g／mask内R／mask内正解／全正解のhead位置誤差・成功・presence。自然：元特徴／全R／学習gの可視・遮蔽点の位置誤差・成功・presence、点位置g。画像群・点別値を保存し動画bootstrapで比較する。成功はpresence0.7かつGT楕円長径誤差10%、以前の診断と同じ。自然遮蔽の裏の正解特徴がないため自然の特徴再現精度は直接算出しない。

関連17テスト通過（拡散vの逆変換、oracle denoiser、seedとbatchの再現性、各枝と時刻への勾配、既存構造と収束／再開）。実データによる24更新の技術確認、head補助とsoft BCEの勾配確認を本比較前に実施する。これは小規模比較であり、本学習を承認する品質gateではない。

canonical GPU leaseを取得して4条件を逐次実行。学習時のソースをread-only snapshotへコピーしてSHAを固定し、実行中のソースを変更しない。状態`status.json`、進捗は出力と同名の`.log`。全条件終了後に固定親・ソース・保持重みを照合する。過去の候補と評価結果は変更しない。

### 自然遮蔽の教師と精度

旧教師コードSHAは`d2100ccfb79d45d0c4f75e82213866160dfa09837eb9ae804a01ae33a4cf9f0c`で旧実験と一致。座標整合、範囲0〜1、soft BCE勾配を確認。自然遮蔽点の平均gは順に0.415／0.401／0.393／0.395、可視点0.091／0.087／0.084／0.085。「復元特徴をほぼ使わない」以前の位置損失のみの条件とは異なり、遮蔽点で約4割採用している。

しかし自然遮蔽の平均位置誤差は全条件で元特徴より大きい。可視点も平均誤差2.203%→2.343／2.349／2.375／2.380%と悪化し、各差の動画bootstrap95%区間はゼロを含まない。成功数の増加だけを位置精度の改善としない。

Diffusionの元特徴に対する自然遮蔽成功率差は両条件+0.860ポイント。95%区間は特徴のみ−2.888〜+4.835、head補助あり−2.431〜+4.745で、ゼロを含む。回帰へのhead補助で+5点だが、成功率差区間−0.474〜+3.690ポイント、平均誤差差もゼロを含む。拡散へのhead補助は成功数不変、平均誤差は小幅悪化。探索的・単一seed・多重比較未調整で、補助損失の安定した自然位置改善は確認できない。

追加の探索的な精密位置診断（学習・選択には使っていない）では、presence≥0.7かつ誤差5%以内の自然遮蔽成功は元182/349に対し163／170／168／167。中央値も元4.429%→5.063／4.976／5.102／5.071%と悪化した。presence通過数は元308→313／316／323／324と増加しており、10%成功数と精密な座標復元を区別する必要がある。

### 平均化仮説とDiffusion

GT点周辺3×3の特徴空間分散／正解分散は、回帰0.574／0.583、Diffusion1.784／1.788。拡散は局所変動を増やしたが、正解特徴への誤差は回帰より大きい。局所分散が大きいことを「局所精度が高い」根拠にはできない。観測は平均化への懸念と整合する一方、MSEがhead不改善の唯一の原因という説明や、Diffusionなら解決するという説明を支持しない。

回帰のhead補助による特徴差−0.000639の95%区間は−0.001629〜+0.000303。拡散のhead補助による特徴差−0.000541は−0.000835〜−0.000248と小さく改善したが、自然位置精度に明確な改善はない。Diffusionの特徴誤差は対応する回帰より約0.125大きく、両区間ともゼロを含まない。

モデル学習seedは42だけ。生成ノイズseed42/1042/2042/3042では、拡散・特徴のみの自然遮蔽成功が260／255／265／262、head補助ありが260／257／264／264。生成ノイズの変更を、別の学習seedによる再現性検証とは呼ばない。最良の生成seedを選択して報告しない。
