# Messenger復元特徴の離散化と遮蔽分布の設計（2026-11-21）

状態：構造はユーザー承認済み。遮蔽領域の多様性確保・分布維持を設計に追加。以下の生成・監査方式はその要件を具体化した実装方針。モデル／生成器の変更・追加学習は未実施（not run）。過去の実験結果・不合格・完了記録は保持する。

## 承認された復元経路

遮蔽画像 → 固定DINO特徴X → Messengerが各patchの384次元復元特徴Fを予測 → encoderで16/32次元へ圧縮 → codebookで離散コードを選択 → decoderで384次元Rへ復号 → Y=(1-g)X+gR → 固定keypoint head。

- 現行のP(X)+M(X)を廃止する。元DINO特徴Xやその圧縮値を、Messengerの復元予測へ直接足し戻さない。MessengerによるXへのcross-attention参照は維持する。Transformer内部の残差接続とは区別する。
- codebookの前に384次元の復元予測Fを置く。現行の16/32次元の補正量予測と同一視しない。Fへの直接補助損失は未確定で、承認済み構造から自動的に追加しない。
- 最終的にcodebook復元を適用するのは遮蔽領域。g=0の位置はXをそのままheadへ渡す。全patchのRを計算することと、headに採用する領域は区別する。
- 今回の比較は教師g固定。将来のg推定はdecoder後のR、X、差分を参照する構想で、別課題。自然遮蔽のgは既存5点注釈由来の弱教師であり、人工の既知maskと混同しない。
- head位置誤差を主目的、遮蔽前DINO特徴を復元補助の教師とする。clean教師特徴をheadへ渡す比較は禁止を維持する。

## 遮蔽率と分布維持

遮蔽率は、RGB画素での「人工遮蔽maskとGT顔楕円の共通面積 / GT顔楕円の面積」。画像全体の面積比やfeature patchの置換率ではない。

階級は[0,20)、[20,40)、[40,60)、[60,80)、[80,100]%の5階級。最後の階級だけ100%を含む。fit/dev/evalそれぞれで各階級20%を目標とする。学習では各epochで同数になる割当表を先に作り、端数は最大1例差にして持ち越しで偏りを抑える。階級内の目標遮蔽率も均等に抽出し、特定の境界付近への偏りを検査する。

1. 顔・遮蔽率階級・目標率・位置・形状を先に割り当てる。
2. 生成後に顔楕円との交差面積を実測し、指定階級と目標率への適合を確認する。
3. 不適合は同じ割当を再生成する。別階級の例で埋め合わせたり、不成立例を黙って除外したりしない。
4. 所定の再試行でも不足が解消しない場合は、不足階級・位置・形状と理由を記録して生成検査を不合格にする。未達分布のまま学習へ進まない。

0%・100%は端点の幾何・g動作を別途検査する。0%の端点検査をclean特徴head比較へ拡張しない。100%の結果は情報欠損が極端な層として分けて報告する。

## 遮蔽領域の多様性

- 位置：顔の局所座標で上下・左右・中央・周辺を層別管理し、その中で連続的に移動させる。遮蔽率が同じでも同じ位置だけを覆わない。
- 形状：既存の線・顔・手を含め、細い遮蔽、広い遮蔽、不規則な輪郭、連結した領域と複数に分かれた領域を扱える生成方式とする。形状カテゴリの具体的な数と比率は実装時の定義表に明記する。
- 変換・外観：角度、縦横比、大きさ、色、テクスチャを変化させる。RGBの不透明maskを基本とし、半透明遮蔽の混入は別条件として扱う。
- 点の隠れ方：遮蔽点数0〜5、目・鼻・口のどこを覆うか、両目同時遮蔽などの組合せを記録する。面積率の均等だけで点の隠れ方の多様性を満たしたことにしない。左右を交換した集計も可能にする。
- 顔条件：同じ動画分割を維持し、姿勢・顔サイズ別にも遮蔽率と位置の分布を確認する。顔の選択や形状の生成失敗によって特定条件が消えていないか検査する。
- 幾何的に成立しない組合せ（例えば非常に細い線で顔のほぼ全域を覆う等）は事前に適用可能表へ記録する。全直積の均等を無理に要求せず、各遮蔽率階級内の成立可能なカテゴリで偏りを管理する。生成後に都合よく対象外へ変更しない。

## epoch更新と比較条件の同一性

- fitは顔ごと3mask固定の反復をやめ、epochごとに位置・形状・率・外観を更新する。階級割当数は維持する。
- seedはsplit・顔ID・epoch・sample slotから決定し、同じ条件を再現できるよう生成仕様とmask情報を保存する。モデル条件はseedに含めず、比較モデルは同じepochの同じ遮蔽を使う。
- dev/evalは別seedで固定する。各モデルが同じ顔・同じmaskで評価されるようmanifestを共有する。評価結果を見てmaskを選び直さない。
- 現行は遮蔽画像のDINO特徴を開始時に固定cache化している。epoch更新には、対応する遮蔽画像から特徴を再抽出するか、事前に用意したepoch別cacheを用いる必要がある。maskだけを更新して古い特徴と組み合わせることを禁止する。画像・mask・特徴・教師gのidentityをセットで検査する。

- 新構造のforward経路、元特徴の直接加算がないこと、g=0でhead入力がXと一致すること、g=1でRと一致すること、勾配と辞書更新／評価時固定を確認する。

- 1顔5例、各階級1例。fit256顔1,280例/epoch、dev/eval各128顔640例固定。fitマスクと特徴を毎epoch再生成し、比較条件間の生成manifestとfeature SHA一致を確認する。
- 形状はline/face/hand/ellipse/irregular/multipleの6種。距離場の等値線で顔内面積を実測調整し、階級内目標値を層化抽出。高遮蔽では輪郭の膨張により手・顔らしさや複数領域が失われることがあるため、実連結数も保存。写実的な遮蔽物ではない。
- 位置は顔局所座標3×3anchor＋jitter、形状×位置の割当を均等化。実被覆頻度mapと代表画像を保存する。flat/smooth/pixel textureの3種を形状と交差させる。目標面積許容差は0.1percentage point。実測が指定階級外なら失敗、他階級で補充しない。
- gはRGB遮蔽maskの16×16画素patch max-pool、顔support閾値による切り捨てを廃止。遮蔽点の所属patchに必ずg=1。g=0の位置はbitwiseにXを保持する。patch内の未遮蔽画素にもRが適用される境界差は記録する。
- 位置主損失＋0.01遮蔽領域特徴MSE＋0.01cosine＋0.01(code＋0.25commitment)。非遮蔽R補助損失なし、Fへの直接補助損失なし。辞書Bは勾配更新、D/Eは遮蔽tokenのみEMA。全条件DINO/head固定、教師g固定、自然弱教師gは評価のみ。
- 選択はdev位置最小、従来のplateau条件・seed42・AdamW lr1e-4・effective batch16を維持。microbatch4/8/16の繰返し更新＋検証を計測し、最速16を選択。OOM時はepoch前のモデル/optimizer/RNGを復元しmicrobatchを半減する。
- 10%/20%超は記述的な大誤差指標とし、正式な崩壊閾値の採用とは扱わない。各階級で平均・p95・救済・新規悪化を保存する。
- W&Bは専用scalar同期プロセス。数値評価・比較・監査完了後、今回の30checkpointと初期辞書4ファイルのみSHA/パス/プロセス確認後に削除する。

## Baseline学習データとの重複確認（2026-11-21）

- ユーザーが生DINOの高精度とデータリークを指摘。baselineの学習成功記録・設定・train注釈・実checkpointのSHAを照合し、評価元画像／顔がbaseline学習に含まれることを確定。
- 人工eval128顔（119画像・35動画）は全件、baselineの学習対象の同一顔・同一画像。自然eval512顔（459画像・40動画）も全件。表示15例も全件。人工evalのkeypoint注釈は123/128顔で当時と同一、顔楕円は128/128同一。修正注釈になっていても画像の学習履歴は消えない。
- 復元器のfit/dev/evalの動画・画像SHA重複は0だが、その全域をbaselineは学習済み。モデル全体の未見データ評価としては成立しない。既存結果はbaseline既知画像への新規人工遮蔽を用いたtrain内診断として保持し、codebookの一般的な優劣や未見遮蔽耐性の結論に使わない。
- 生DINOは事前学習DINOそのものではなく、baselineのkeypoint学習でfine-tune済みのDINO。baselineは遮蔽augmentationも使用。rawは遮蔽RGBをDINOへ入力した特徴のみをheadに渡し、clean特徴やGT点はheadに渡さない。15例の独立再推論が保存済み評価と一致するため、画像だけ遮蔽してclean特徴で評価する取り違えは見つからない。
- GT楕円から中心・大きさ・回転を与えたcrop、教師gもoracle条件。80–100%階級の平均遮蔽は顔内90.0%だが入力crop全体59.4%で、周辺情報は残る。学習画像重複・GT crop・周辺情報の寄与量は未分離であり、高精度が記憶だけによると断定しない。
