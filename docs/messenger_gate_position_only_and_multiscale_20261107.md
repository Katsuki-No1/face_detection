# 位置誤差だけで学習した採用率と、人工遮蔽でのmulti-scale復元

## 自然画像での採用率

V3 train内で前回と同じ2,048顔を学習に、別の40動画768顔を評価に使用。主条件は座標注釈のある全点を等重みにし、固定headの座標Smooth L1（crop正規化、beta 0.02）のみを g へ逆伝播した。学習時の補間マップ生成とBCEを外した。DINO、候補R、チャネル係数、headは凍結。前回と同じseed 42、8 epoch、batch 16、AdamW 5e−4。各条件で実データの位置損失からlogitへの勾配を確認し、終了時に親モデルの状態ハッシュが一致した。

| gの条件 | 遮蔽／可視での平均g | 遮蔽位置成功 / 479 | 可視位置成功 / 2,806 | 遮蔽／可視の平均誤差 |
|---|---|---:|---:|---|
| 0 | 0 / 0 | 320 | 2,620 | 7.605% / 2.520% |
| 前回のsoft BCE＋位置 | 0.513 / 0.086 | 324 | 2,623 | 7.352% / 2.529% |
| 位置のみ・全点等重み | 0.373 / 0.115 | 327 | 2,631 | 7.365% / 2.425% |
| 位置のみ・前回と同じ群別重み | 0.398 / 0.165 | 327 | 2,630 | 7.335% / 2.470% |

成功はpresence ≥ 0.70かつ誤差 ≤ GT顔楕円長径の10%。平均誤差は全注釈点での楕円長径比。群別重みの対照は、前回の位置損失を維持しBCEだけを除いた比較である。遮蔽点を高いgにする順位性能（AUROC）は前回0.927、全点等重み0.747、群別重み0.702。全点等重みと前回の遮蔽成功率差は+0.63ポイント、動画単位の対応付きbootstrap 95%区間は−0.54〜+1.84ポイント。可視点での平均誤差差は−0.104ポイント（−0.212〜−0.026）。親のV2 train/valと動画名が一致するものを除くと、遮蔽点で217→220 / 356点、可視点で1,697→1,704 / 1,832点。同じ開発集合・単一seedでの比較である。

ゲートの強さを直接調べる追加介入として、全パッチで推論時のみ g を min(2g,1) とした。前回ゲートでは遮蔽位置成功324→326、平均誤差7.352%→7.375%、可視位置成功2,623→2,622。位置のみ・全点等重みでは遮蔽位置成功327→329、平均誤差7.365%→7.328%、可視位置成功2,631→2,632、可視平均誤差2.425%→2.439%。この倍率は診断用である。[介入結果](../outputs/diagnostics/natural_gate_position_only_20261107/gain_probe.json)

## 人工遮蔽での復元

同じk=3親モデルから復元器を2つ初期化し、凍結DINOの最終層16×16特徴を使用した。一方はそのままの256トークン、もう一方は同じ特徴を平均poolした8×8と4×4も連結した336トークンを参照する。位置情報の線形層は両条件に同一のゼロ初期値で付けた。学習前に単一スケールの出力と親Rの一致を確認した。各条件で同じ順序の学習画像・人工マスクを用い、同じ参照座標層とMessenger token・復元層・decoderを更新。学習は256顔から合成した765対、4 epoch、batch 16、AdamW 1e−4。損失は固定observerの遮蔽前特徴へのコサイン距離＋MSEを、楕円内の遮蔽パッチ重み1・非遮蔽パッチ重み0.1でそれぞれ平均した。

前回と同じ評価用128顔・383合成対・遮蔽10,251パッチ。位置損失のみで学習した全点等重みgを固定し、同じ553個の実際に人工マスクに覆われた点を評価した。

| Rの条件 | Rのコサイン距離 | RのMSE | 融合後のコサイン距離 | 位置成功 / 553 | 位置平均誤差 |
|---|---:|---:|---:|---:|---:|
| 追加学習前の親 | 0.17449 | 0.04530 | 0.28118 | 523 | 4.018% |
| 単一スケールを追加学習 | 0.12909 | 0.03530 | 0.26785 | 527 | 3.982% |
| multi-scaleを追加学習 | 0.12954 | 0.03542 | 0.26755 | 527 | 3.979% |

元特徴Xのコサイン距離は0.30191。multi-scale − 単一スケールのRコサイン距離差は+0.00044（動画bootstrap 95%区間 +0.00029〜+0.00060）。追加学習は両条件で復元誤差を下げた。スケールを増やす固有の改善は今回の予算・構成では観測できなかった。自然遮蔽の裏側の特徴や、復元器変更後の自然遮蔽head性能は別の評価対象である。

学習条件、ゲート重み、対応付き区間は[位置損失の実験](../outputs/diagnostics/natural_gate_position_only_20261107)、合成対のmanifest、両復元器、コサイン距離とMSEの比較、固定した新gでのhead評価は[復元スケールの実験](../outputs/diagnostics/natural_gate_recovery_scales_20261107)に保存した。
