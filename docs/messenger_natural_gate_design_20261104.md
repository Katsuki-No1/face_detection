# Messengerの自然遮蔽と復元採用率の設計（2026-11-04）

**2026-11-07 暫定採用。** 自然遮蔽下でMessengerの復元候補をどこでどれだけ使うかを学ぶため、trainの5点注釈から顔楕円内の遮蔽候補を連続値で表す。遮蔽された目と口角の間に顔の上下軸上で可視の鼻が来る場合は、鼻の高さに仮の谷底を置き、辺上の遮蔽度を1→0→1と滑らかに変える。顔ID 2で試作したのは遮蔽度そのものを下げる方式。額・顎など注釈点の外周から延長した値には、距離に応じて低い学習重みを与える設計とする。

人工遮蔽で学んだ復元候補 R を固定し、この候補領域を無加工の自然画像上でパッチごとの融合係数 g の弱い教師に使う。自然遮蔽点で得られる実座標の損失も使い、同じ点での g=0 との比較により復元採用が位置推定に寄与するか確かめる。現時点の確認範囲は顔ID 2での補間の挙動。自然遮蔽点の位置精度への効果は未測定。

## 検討の経緯

**元画像での確認結果（2026-11-04）：5点の2次元配置から遮蔽領域を補間する案は保留。** 課題は、横顔での奥行きと、特に目と口の間で遮蔽がどこまで続くかの扱いにある。画像上で目と口角を線で結べても、その間が同じ遮蔽領域に属するとは限らない。ユーザーの目視では、横顔で奥側の目と鼻がともに写っていない例で、教師マップ上では鼻の位置が可視側になり、遮蔽領域が実際の見え方と合わなかった。この指摘は補間した教師マップに対するもの。鼻の点注釈と補間処理のどちらに由来するかは未確認。

## 元画像の検討と学習方針

2026-11-07の追記。実注釈「2点遮蔽・正面寄り」（顔ID 2）では、右眼と右口角が遮蔽、鼻が可視である。元画像の y は右眼279.20、鼻364.17、右口角387.60 px の順。鼻の高さで右眼と右口角を結ぶ線は x≈1030.0 px、鼻は x=1070.61 px にある。現方式の三角形分割には右眼と右口角の直結辺があり、鼻の重みは辺上で0になる。このため辺上の教師値は全域で1になる。見える中間領域まで遮蔽とするという指摘は、この例では鼻の点自体の誤分類よりも、目から口角へ遮蔽を連続させる制約に関係する。

保留中の検討案として、目と口角の間の高さに可視の鼻がある場合、その2点のラベルだけで辺の内部を強い教師にすることを避ける。顔の上下軸で測った位置が目・鼻・口角に一致するとき順に 0・u・1 とし、目と口角を結ぶ辺上で監督の強さを 1・0・1 と滑らかに補間する案がある。鼻そのものには可視の点教師を与える。鼻から横に離れた位置で本当に遮蔽が途切れるかは未注釈であり、そこを可視と教えるには別の根拠が要る。この案は未採用。

新しい比較条件では、パッチごとの融合判断を連続値 (g) に任せる。元特徴を X、Messengerの復元候補を R、既存のチャネル係数を c とすると、Y = X + g c (R − X)。旧式の異常マスク m を融合の必須条件から外す。c はまず固定し、空間的な採用の変化を g に帰属できるようにする。

人工遮蔽を追加する前後の同一顔・同一幾何の対を使い、貼り付け前の特徴を教師として R を学習する。次に特徴抽出器・R・c・座標headを固定し、追加加工のないtrain画像で g を学習する。自然遮蔽点と可視点の注釈から作る採用率教師と、固定headを通る位置損失を使う。人工対の採用率教師と人工画像のタスク勾配はこの段階に流さない。GTの点・状態・教師マップを使うのは訓練時だけである。自然遮蔽の裏にある特徴そのものの正解は得られない。

統計的な非遮蔽顔との比較は独立の比較候補として保存する。非遮蔽パッチの特徴分布を学び、入力パッチの逸脱から遮蔽を検出する研究例がある。既存のk=3参照バンクには特徴中心・幾何中心・位置別閾値があり、連続した逸脱スコアも得られる。疎な自然遮蔽GTによる専用判定枝や、このスコアを補助入力にする方式の効果は未検証である。[Lee et al., ICCV 2023](https://openaccess.thecvf.com/content/ICCV2023/html/Lee_Latent-OFER_Detect_Mask_and_Reconstruct_with_Latent_Vectors_for_Occluded_ICCV_2023_paper.html)

## 5点から作る連続教師の案

対象は顔楕円内。座標が有効な左右眼・鼻・左右口角を基準とし、自然遮蔽点の中心に1、可視点の中心に0を置く。state 0は不明として除く。点間の値は疎な注釈から補間する訓練用の採用目標である。2つの遮蔽点を同じ物体が覆っているかは観測されていない。

具体案として、楕円の軸に揃えた座標系で観測点を三角形に結び、三角形内では3頂点の状態を重み付き平均する。各頂点の重みは重心座標に対する滑らかな単調関数を通してから総和1に正規化する。例として、0から1で端が平坦になり中央を中心に対称な h(t) = 3t² − 2t³ を使える。正の高さではなく寄与率を補間するので、頂点ではその点だけが重み1、別の頂点では元の点の重みは0になる。隣り合う2頂点がともに遮蔽なら、その辺上の教師値は途中も1である。片方が可視なら連続的に1から0へ移る。ガウス形状自体は確定要件とせず、対称性と点間距離に応じた滑らかな遷移を優先する。

横顔で遠い側の目と鼻の投影距離が短くなると、同じ重みの変化が短い距離で起きる。実際の5点配置だけでは奥側の目の担当面積が常に小さくなる保証はない。姿勢別に各点の寄与面積を可視化し、横顔で過大なら、trainの同姿勢群の投影間隔で点ごとの影響幅を制約する案と比較する。

楕円内でも観測点の凸包外では最も近い辺の補間値を延長し、辺から離れるほど**損失の重み**を小さくする。教師値と根拠の強さを分け、点がない額や頬を強い可視・遮蔽の教師にしない。2点・共線なら線分、1点なら近傍だけ、0点ならこの顔のマップ損失を省く。楕円外にあるGT点はマップ教師から除き件数を残す。重なる点の矛盾は両方を厳密に満たせないため、該当セルの監督を弱めるか除外する。パッチ内では教師の値と重みを面積集約する。

## 検証で切り分けること

最初にtrain上で教師マップを可視化し、左右反転、横顔、点の欠損、同じ状態の隣接点間に人工的な谷ができないことを確認する。自然画像の同一条件で「g=0」「旧mを含む融合」「mを外して自然遮蔽でgを学習」を区別する。mを外す効果だけを比べる場合は、復元器・head・自然画像・採用率教師を揃えた上でmの有無を比較する。自然遮蔽点と可視点について g・実効補正量・点の出力率・位置成功率を別々に記録する。専用判定枝の追加は独立比較とする。ここまでの成果は設計と既存診断の再集計で、新方式の精度は未測定。
