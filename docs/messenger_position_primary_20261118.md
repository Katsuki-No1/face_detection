## 実行前に固定した条件

- 過去と同一の小規模train内動画分割。人工fit256/dev128/eval128顔×3形状、自然fit512/dev128/eval512顔。本学習・global val/testではない。
- V3 backbone/head固定、回帰・DFはseed42で新規初期化。同じscale1/2/4独立attention幅96。DFは16stepのvパラメータ化DDIM相当更新。
- 共通損失：`L_position + 0.01*MSE(R,Z) + 0.01*(1-cos(R,Z))`。位置はGT顔楕円長径で正規化したEuclidean距離、人工の遮蔽／未遮蔽GT点を別平均して等重み。特徴の領域集計は遮蔽平均＋0.1×楕円内非遮蔽平均。headにはmask内R／外Xを渡す。Zは特徴教師としてのみ使用。
- DFは純粋ノイズからの16step生成結果へ共通損失をかけ、全stepに逆伝播する。学習用noisy cleanから1回復元した結果への代用はしない。各epochで共通seed42+1009×epoch、ID固定ノイズ。devはseed42固定。
- DFの通常のv教師MSEは追加しない。今回は確率的反復生成器を最終目的で直接学習する比較であり、従来のdenoising/score-matching目的を主とする比較とは異なる。各枝の教師損失・枝間一致も両条件で外し、最終出力の共通目的に揃える。
- 初期lr R1e-4/g5e-4、AdamW weight decay0.01、clip5。R microbatch4・effective16、g batch16。FP32/TF32、自然RキャッシュもFP32。FP16キャッシュで方式差を作らない。DINO入力特徴キャッシュは過去と同じFP16→FP32。
- Rはdev位置誤差最小を選択。位置と全損失のplateauを監視し、最低40epoch、8epoch停滞でlr半減、下限1e-6で15epoch停滞なら終了。600epochの安全上限は収束とは扱わない。
- R固定後、自然遮蔽gを学習。旧5点補間のsoft遮蔽教師を同じコードで再利用。自然位置（遮蔽／可視の別平均を等重み）＋0.01 confidence-weighted BCE。gも位置誤差で選択、最低20epoch、lr下限5e-6、8/15patience、上限300。
- 自然gの学習経路とRの人工mask経路は異なるため、その限界は保持。今回はRとgの同時最適化ではない。
- 評価：人工の特徴誤差・GT点近傍誤差・局所変動、人工／自然の座標誤差分布と2/3/5/10%成功。座標のみとpresence0.7込みを分離。DFは42/1042/2042/3042の生成seedを個別評価。seedのbest-of選択なし。
- 正解特徴をheadに渡す入力は作らない。全8重みbest/last R/gを保持し削除なし。固定親・source・data SHA、canonical GPU lease、同一planに限るresume。

## cosineだけを特徴補助にする場合の考察（2026-11-19、未学習）

直前のユーザー方針を維持するなら、head位置損失を主に保ち、特徴MSE係数を0、cosine距離の係数は同じ0.01にする。他を変えずにMSEの寄与を分けられる。head位置損失まで除く純粋cosine学習とは別の条件である。

非ゼロ特徴R,Zについて、`||R-Z||² = (||R||-||Z||)² + 2||R||||Z||(1-cos(R,Z))`。MSEはこれをチャンネル数で割ったもの。cosineだけでは方向を合わせるがノルムは拘束しない。例えばR=ZとR=10Zは同じcosine1になる。振幅の再現に使っていた学習を方向へ振り向ける可能性がある一方、現在のheadやg融合が振幅不変とは限らず、normのずれが位置に悪影響を与える可能性もある。

cosineへ替えても平均化の問題が消えるとは言えない。単純な条件付きcosine目的でも、最適な出力方向は正規化した教師方向の条件付き平均の方向になり得る。近傍パッチの位置関係も、各点のcosine一致だけで特別に監督されるわけではない。

実行する場合の確認項目は、位置誤差・厳しい成功閾値、特徴cosine、特徴ノルム比／分布、g採用率、局所差分。MSEは学習から外しても評価値として残す。今回の特徴補助は既に0.01と小さく、MSEを外すだけで劇的に改善する根拠はない。DFも今回は生成終端の共通損失なので、v教師MSEを変更する話ではなく最終生成特徴MSEを外す比較になる。学習・損失実装の変更は今回行っていない。
