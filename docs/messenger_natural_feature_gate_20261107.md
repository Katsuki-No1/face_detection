# 自然遮蔽の教師と位置損失によるMessenger採用率の学習

2026-11-07。顔crop後の既存Messenger k=3 EMAを使い、DINO特徴 X、人工遮蔽で学習済みの候補 R、チャネル係数 c と Query Refinement head を固定した。新規のパッチ単位MLPにX、R、両者のコサイン距離、crop内の位置を与え、各logitのsigmoidを g とした。headに渡す特徴は Y = X + g c (R − X)。同じ画像で g=0 と置くと元特徴 X からの位置推定を再現する。

## 教師と学習条件

回転軸補正済みV3 trainの自然画像からGT楕円で256×256の顔cropを作った。学習は163動画2,048顔、評価は別の40動画768顔。両群で動画IDと元画像SHAの重複は0。新規ゲート用の動画分離であり、凍結済みの親のV2 trainには評価群の255顔分と同一SHAの元画像がある。公式val/testの成績や検出器を含む性能とは評価範囲が異なる。

5点の自然遮蔽注釈（遮蔽1、可視0）から楕円内の連続教師を作った。同じ側の眼と口角が遮蔽され、その間の顔軸の高さに可視の鼻がある場合、眼と口角を結ぶ直線に教師値0の仮の谷底を加える。欠損は除外する。観測点の凸包外では最近接辺の値を延長し、損失の重みを距離に応じて減らす。16×16の各特徴パッチに4×4の位置サンプルで面積集約し、支持面積と教師の信頼度で重み付けする。密な真の遮蔽マスクは利用していない。

目的関数は 0.1 × 重み付きBCEWithLogitsLoss + 1.0 × 位置Smooth L1。位置はcrop正規化xy、beta=0.02、自然遮蔽点と可視点の各群で平均し等重みで合成。予測presenceにかかわらず注釈ありの点を監督した。BCEの係数・座標損失の単位・学習予算は今回の実験設定である。seed 42、AdamW、LR 0.0005、batch 16、8 epoch（1,024更新）、最終epochを評価。実データで両損失のlogit勾配が有限かつ非ゼロ、凍結モデルの状態ハッシュは更新前後で一致した。

## 性能

| GT点の状態 | 点数 | 平均g | g=0 の位置成功 | 学習gの位置成功 | 全注釈点での平均位置誤差（g=0 → 学習g） |
|---|---:|---:|---:|---:|---:|
| 自然遮蔽 | 479 | 0.513 | 320（66.81%） | 324（67.64%） | 楕円長径の7.61% → 7.35% |
| 可視 | 2,806 | 0.086 | 2,620（93.37%） | 2,623（93.48%） | 楕円長径の2.52% → 2.53% |

位置成功はpresence ≥ 0.70かつ誤差 ≤ GT楕円長径の10%。平均位置誤差はpresenceによる足切りなし。過去のGT Head正規化値との比較には用いない。実注釈点で遮蔽を正例にしたgのAUROCは0.927。閾値0.5でTP 218、FP 86、FN 261、TN 2,720（適合率71.71%、再現率45.51%）。補間教師に対する重み付きBCEは0.217、RMSEは0.213。AUROC、固定閾値での識別、位置推定は別々に解釈する。

同じ凍結親と保存済みゲートを再ロードし、全体指標を再現した。遮蔽点は融合で失敗→成功が11点、成功→失敗が7点。動画単位の対応付きbootstrap（10,000回）による位置成功率差の95%区間は−0.95〜+2.56ポイント、平均位置誤差差は楕円長径の−0.41〜−0.11ポイントだった。

親のV2 train/valと元動画名が一致する画像を除いた追加集計は31動画513顔。遮蔽356点でAUROC 0.926、平均位置誤差8.56%→8.27%、位置成功218→217点だった。平均誤差の低下は両集計で見られたが、成功点数の増加はこの集計で再現しなかった。動画名による除外が対象にするのは特定のV2インベントリであり、基盤モデルの事前学習履歴全体を照合したものではない。

## 人工遮蔽の前後対による復元の確認

同じ評価動画のうち、5点がすべて可視で輪郭の遮蔽フラグもない316顔から固定ハッシュ順に128顔（36動画）を抽出した。各顔に3種類の人工遮蔽を加え、矩形128、不規則形128、境界型127の計383対で同じcrop内の特徴を比較した。境界型1件は配置不成立。教師は遮蔽追加前の同じ画像を固定observerに通した特徴。顔楕円内で1 pixel以上貼り付けと重なるパッチをまとめて平均した。Xは遮蔽入力の元特徴、Rは凍結復元候補、Yは学習済みgによる融合特徴である。
