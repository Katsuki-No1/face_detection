# スプレッドシート集計GAS

Googleスプレッドシート「ワーカーさんのタスク状況」の月別情報を集計し、まとめシートへ反映するためのGASです。

## 仕様の扱い

- 本READMEを実装・運用ルールの基準とする。
- 実装または仕様変更を行う前に、必ず本READMEの記載を確認する。
- 仕様が変更された場合は、GASと同時に本READMEも更新する。
- 本READMEと実際のシート構造に相違や不明点がある場合は、推測で実装せず、確認して仕様を明確にしてから変更する。

## スプレッドシートの目的

- タスクの進行状況を把握する。
- HEAD数から単価を把握する。
- 月ごとのコミット状況を把握する。
- 修正量や連絡に関する印象を記録し、認識を共有する。

## シート構成

スプレッドシートは次のシートを持つ。

1. `全体の内容`：GASが生成・更新するまとめシート
2. `○月の進捗`：月ごとのタスク進行度を記録するシート

月別シートは、スプレッドシート上の並び順でまとめシートへ表示する。新しい `○月の進捗` シートを追加すると、次回更新時に自動的に集計対象となる。

### 月別シートの入力構造

各メンバーは原則として次の10行で構成する。

| 行 | 内容 |
|---|---|
| 1 | A列に名前 |
| 2 | B列以降に `task1`、`task2` のようなtask番号 |
| 3 | task作成 |
| 4 | 作業完了 |
| 5 | 確認 |
| 6 | 修正連絡 |
| 7 | 修正完了 |
| 8 | HEAD数 |
| 9 | frame数 |
| 10 | 空行 |

task番号は末尾の数字を使用する。このため、既存の `tas1` は `task1` として扱う。数字のない `test` などはtask集計の対象外とする。

## まとめシートの項目

- 名前
- 加入日
- 月ごとのHEAD数
- 月ごとのtask数
- 月ごとのframe数
- 現在何個目のtaskか
- HEAD数の合計
- frame数の合計
- 修正の量の印象
- 連絡の印象

## 集計ルール

### HEAD数

- 表示名、README、コード内の用語を「HEAD数」に統一する。
- 「カウント数」などの別名は使用しない。
- 各月・各メンバーについて、task番号がある列のHEAD数を合計する。
- HEAD数の空欄は `0` として扱う。
- 「修正完了」が `〇` でもHEAD数が未入力の場合は、入力されるまで `0` として集計する。
- 「HEAD数の合計」は、対象となるすべての月別シートのHEAD数をメンバーごとに合計する。

### frame数

- 各月・各メンバーについて、task番号がある列のframe数を合計する。
- frame数の行がない場合や、値が空欄の場合は `0` として扱う。
- 「frame数の合計」は、対象となるすべての月別シートのframe数をメンバーごとに合計する。

### task数

- 月ごとの `task数` は、その月に完了したタスクの件数を表す。
- 「修正完了」行に `〇` または `○` があるtaskを完了と判定する。
- 「作業完了」など、ほかの行の印だけでは完了と判定しない。
- task番号がある列のうち、完了と判定された列を1件ずつ数える。
- 例：その月のtask番号が `5, 6, 7, 8` で、`5, 6, 7` が完了している場合、task数は `3` とする。

### 現在何個目のtaskか

- 完了タスク番号の最大値に `1` を加えた値とする。
- 月ごとのtask数とは別に、全期間の完了task番号から最大値を取得する。
- 例：完了タスク番号の最大値が `7` の場合、現在のtaskは `8` とする。

### 印象欄

- 「修正の量の印象」と「連絡の印象」は手入力する。
- GASによる自動更新では、既存の手入力内容を上書きまたは削除しない。

### 加入日

- 加入日は `全体の内容` シートで手入力する。
- GASによる自動更新では、既存の手入力内容を上書きまたは削除しない。

## 更新タイミング

- スプレッドシートを開いたとき、`onOpen()` から集計情報を自動更新する。
- 自動更新の対象はHEAD数、task数、現在のtaskなどの集計項目とする。
- 手入力の加入日と印象欄は自動更新の対象外とする。
- カスタムメニュー「集計」から手動更新することもできる。

## まとめシートの表示

- 1人につき1行で表示する。
- 基本情報として、名前、加入日、現在のtask、HEAD数の合計、frame数の合計、2つの印象欄を表示する。
- 月ごとに「HEAD数」「task数」「frame数」の3列を表示する。
- 加入日と印象欄は手入力列として色分けする。
- 自動集計列と月別グループを色分けし、見出し固定、フィルター、罫線、列幅調整を適用する。
- 最終更新日時を上部に表示する。

## エラー時の扱い

- 対象となる月別シートやメンバーが見つからない場合、まとめシートを消去せずエラーとして停止する。
- 同時実行を防ぐため、更新処理ではドキュメントロックを使用する。
- 自動更新に失敗した場合はログへ記録し、スプレッドシート上へ通知する。
